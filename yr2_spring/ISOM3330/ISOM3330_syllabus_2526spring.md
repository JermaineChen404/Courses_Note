# Data Visualization and Visual Analytics (ISOM3330) — Spring 2026 (AY 2025-26)

## Course description
This course covers principles and techniques for designing, building, and evaluating data visualizations and visual analytics systems. Topics include visual encoding, interaction techniques, evaluation methods, visualization libraries/tools, and applications to real data.
